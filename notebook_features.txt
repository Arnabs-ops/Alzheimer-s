✅ DATA LEAKAGE DETECTION (6-stage safety)
   1. Target leakage: Drops columns identical to y
   2. Zero variance: Removes non-informative features
   3. Duplicate columns: Eliminates redundant features
   4. Near-duplicate correlation: Removes highly correlated features (>0.999)
   5. Train/test overlap: Removes duplicate rows from test set
   6. Sanity check: Permuted-label accuracy test
